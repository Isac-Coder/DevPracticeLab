# DevPracticeLab

DevPracticeLab es una plataforma educativa para practicar habilidades reales en SSH, Docker, PostgreSQL y TypeScript.

La experiencia combina retos, documentación oficial, editor de código y seguimiento de progreso en una sola interfaz de aprendizaje técnico.

## Qué ofrece

- Práctica guiada por módulos
- Retos semanales y progresión por niveles
- Editor de TypeScript con validación real
- Entorno SQL interactivo con tablas dinámicas
- Documentación técnica basada en fuentes oficiales
- IA de asistencia y ayuda contextual
- Perfil de usuario y suscripción por módulos

## Módulos principales

- SSH
- Docker
- PostgreSQL
- TypeScript

## Cómo funciona

1. El usuario entra a la plataforma.
2. Elige el módulo que quiere practicar.
3. Completa retos, consulta documentación y ejecuta ejemplos reales.
4. El sistema registra progreso y acompaña el aprendizaje.

## Stack principal

- Next.js
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Supabase

## Objetivo

Ayudar a personas que quieren mejorar sus habilidades técnicas de forma práctica, progresiva y aplicada, sin depender solo de teoría.

## Uso local

```bash
npm install
npm run dev
```

Luego abre:

```text
http://localhost:3000
```
