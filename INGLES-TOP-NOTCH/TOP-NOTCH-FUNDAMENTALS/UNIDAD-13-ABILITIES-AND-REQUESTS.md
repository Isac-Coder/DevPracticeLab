## 2. 🧠 Gramática principal: CAN / CAN'T y peticiones educadas

### CAN para habilidades

`Can` expresa capacidad — lo que alguien sabe hacer o es capaz de hacer.

```
Subject + can / can't + verb (base)
```

| Tipo | Ejemplo |
|---|---|
| Habilidad positiva | I **can** speak English and Spanish. |
| Habilidad negativa | She **can't** drive. |
| Pregunta | **Can** you code in TypeScript? |
| Respuesta | Yes, I can. / No, I can't. |

---

### Peticiones educadas — escala de formalidad

| Modal | Formalidad | Ejemplo |
|---|---|---|
| `Can you...?` | informal | Can you help me? |
| `Could you...?` | más educado | Could you send me the file? |
| `Would you mind...?` | muy educado / formal | Would you mind closing the door? |
| `Can I...?` | informal (pedir permiso) | Can I ask you something? |
| `Could I...?` | educado (pedir permiso) | Could I borrow your charger? |
| `May I...?` | formal (pedir permiso) | May I speak with the manager? |

---

### Ofrecer ayuda

| Expresión | Uso |
|---|---|
| Can I help you? | ofrecimiento informal |
| Would you like some help? | ofrecimiento educado |
| Do you need any help? | pregunta de ayuda |
| Let me help you. | ofrecimiento directo |
| I'll do it for you. | ofrecimiento espontáneo |

---

### Responder a peticiones

| Respuesta positiva | Respuesta negativa |
|---|---|
| Sure! / Of course! | I'm sorry, I can't. |
| No problem. | I'm afraid I'm busy right now. |
| I'd be happy to. | Maybe later? |
| Go ahead. (para permiso) | I'm not sure I can. |

## 4. 🔗 Collocations clave

| Collocation | Traducción | Ejemplo |
|---|---|---|
| **ask for** a favor | pedir un favor | Can I ask you a favor? |
| **do** someone **a favor** | hacerle un favor a alguien | Can you do me a favor? |
| **lend** something to someone | prestar algo a alguien | Can you lend me your notes? |
| **borrow** something from someone | pedir prestado a alguien | Can I borrow your charger? |
| **get back to** someone | volver a contactar a alguien | I'll get back to you after the meeting. |
| **look into** something | investigar algo | I'll look into that issue for you. |

> 💡 `lend` vs `borrow`:
> - `lend` → tú das algo a otro: *Can you lend me your pen?* (¿me prestas?)
> - `borrow` → tú recibes algo de otro: *Can I borrow your pen?* (¿te puedo pedir prestado?)

## 5. 🗣️ Casos de uso reales

### Caso 1 — Entrevista de trabajo: preguntas sobre habilidades

> **Situación:** Carlos aplica a su primer trabajo como desarrollador.

```
Interviewer: Tell me about your technical skills.
Carlos:      I can code in JavaScript, React, and TypeScript.
             I can also work with REST APIs and manage databases in SQL.
             I can use Git for version control — I'm comfortable with 
             GitHub and the standard PR workflow.
Interviewer: Can you work with CSS frameworks?
Carlos:      Yes, I can. I use Tailwind CSS regularly. 
             I can also work with Bootstrap, but I prefer Tailwind.
Interviewer: Can you work independently, or do you need supervision?
Carlos:      I can work both ways. I can work independently on small tasks, 
             but I also enjoy team collaboration.
Interviewer: What can't you do yet that you'd like to learn?
Carlos:      Honestly, I can't work with backend frameworks yet — 
             like Node.js or NestJS. But I'm learning. 
             I think I can pick it up quickly.
Interviewer: Great. Could you start next Monday?
Carlos:      Yes, I could! That works perfectly.
```

**Nota gramatical:** `can` para habilidades técnicas reales. `Can you start?` → petición/confirmación. `Could you start?` → más suave/educado del entrevistador.

### Caso 2 — Pidiendo favores entre compañeros (chat de Slack)

> **Situación:** Valentina necesita ayuda con su proyecto.

```
Valentina:  Hey Diego! Can I ask you something?
Diego:      Sure, go ahead!
Valentina:  Could you review my pull request? I've been stuck on 
            a CSS issue for an hour.
Diego:      Of course! Send me the link.
Valentina:  Here it is: github.com/valentina/project/pull/12
             Also — would you mind explaining the error? 
             I can see it in the console but I don't understand it.
Diego:      No problem. I'll look at it now.
             ... Okay, I can see the issue. You're using `position: fixed`
             but you forgot to set a z-index. Can you try adding 
             `z-index: 10` to that element?
Valentina:  Oh! Let me try... YES! It works! Thank you so much!
Diego:      Ha! No problem. Could you do me a favor later?
Valentina:  Of course! What do you need?
Diego:      Can you help me with the TypeScript types on the auth module?
             I can handle the logic but I can't figure out the types.
Valentina:  I'd be happy to! I'll come by your desk at 3.
```

**Nota gramatical:** Escalada natural de formalidad: `Can I ask?` → `Could you review?` → `Would you mind explaining?`. `I'd be happy to` — forma más elegante de decir `yes`.

### Caso 3 — Email formal: solicitud de extensión de plazo

> **Situación:** Ana escribe a su instructor pidiendo más tiempo para entregar.

```
Subject: Request for Deadline Extension — React Project

Dear Mr. Torres,

I hope this message finds you well.

I am writing to ask if I could have an extension for the React project 
deadline. Currently, the submission is due this Friday, October 10th.

Unfortunately, I have been sick this week and could not work on the 
project as planned. I have a doctor's note if you need it.

I can complete the project by Monday, October 13th, if possible.
Would you be able to grant a 3-day extension?

I apologize for the inconvenience. I can assure you that the project 
will be complete and of good quality by the extended deadline.

Could you please let me know if this is possible?

Thank you for your understanding.

Best regards,
Ana María Rodríguez
RIWI — Frontend Development
```

**Nota gramatical:** `Could I have...?` — petición educada. `Would you be able to...?` — ultra-educado para solicitud formal. `Can I assure you` — compromiso + habilidad. Toda la escalada de formalidad visible en el email.

## 6. ⏱️ CAN en distintos tiempos verbales

| Tiempo | Modal / Equivalente | Ejemplo |
|---|---|---|
| **Presente** | can / can't | I can swim. |
| **Pasado** | could / couldn't | I couldn't swim when I was 5. |
| **Futuro** | will be able to | I will be able to drive next year. |
| **Condicional** | could | I could help you if I had more time. |
| **Present Perfect** | have been able to | I've been able to work remotely since 2022. |

> ⚠️ `Can` no tiene forma en Present Perfect ni en infinitivo. Se reemplaza con `be able to`.

---

## 7. ⚠️ Errores frecuentes

### `Can` + `to` + verbo

❌ I can **to** speak English.
✅ I can speak English.
> Modales nunca llevan `to` antes del verbo.

### `Could` como pasado de `can` (habilidad) vs petición

- `I could swim when I was 7.` → habilidad en el pasado
- `Could you help me?` → petición educada (no es pasado)

### `Lend` vs `Borrow`

❌ Can you borrow me your pen?
✅ Can you **lend** me your pen? / Can I **borrow** your pen?
